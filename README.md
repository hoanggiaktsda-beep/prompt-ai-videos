# HOANGGIA AI — Video Prompt Studio

AI-video prompt workstation for architecture and interior design.

## What it does
Turns a design brief into a structured prompt for image-to-video and text-to-video workflows:
- Space / subject lock
- Camera angle, lens and verticals
- One primary camera movement
- Secondary motion and people
- Lighting, time of day and atmosphere
- Materials and visual finish
- Geometry and continuity constraints

## Design
A new branch of the HOANGGIA AI visual language: black editorial UI, architectural grid, restrained gold accents and compact studio controls.

## GitHub Pages
Enable **Settings → Pages → Deploy from a branch → main / root**.

The prompt writer is fully client-side and does not require an API key.
