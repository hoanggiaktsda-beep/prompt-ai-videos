# HOANGGIA AI Vision Backend\n\nWorkflow: Master Image → Vision AI → Spatial Blueprint → Geometry Guard → Prompt.\n\n## Cloudflare Worker\n\n1. Tạo Cloudflare Worker.\n2. Dán `worker.js`.\n3. Cấu hình secret: `wrangler secret put OPENAI_API_KEY`.\n4. Có thể đặt variable `ALLOWED_ORIGIN` = `https://hoanggiaktsda-beep.github.io`.\n5. Deploy Worker.\n6. Trong HOANGGIA AI, nhập URL Worker vào Backend URL.\n\nGitHub Pages chỉ phục vụ frontend tĩnh; backend phải chạy trên runtime server-side. Worker dùng OpenAI Responses API với model GPT-5.6 Luna để nhận ảnh và tạo Spatial Blueprint có cấu trúc.
